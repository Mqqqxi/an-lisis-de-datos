# RetailPro - Proyecto de Análisis de Datos

## Descripción

RetailPro es un proyecto académico desarrollado durante el curso de Análisis de Datos. El objetivo es construir un flujo completo de análisis, comenzando por el diseño de una base de datos relacional, la creación de consultas SQL, el proceso ETL en Power BI y la elaboración de dashboards para apoyar la toma de decisiones.

El proyecto utiliza un caso de negocio de una empresa distribuidora de tecnología, aplicando buenas prácticas de modelado de datos, limpieza de información y análisis de indicadores.

---

## Objetivos

- Diseñar un modelo relacional normalizado (3FN).
- Implementar la base de datos en PostgreSQL.
- Crear consultas SQL para responder preguntas de negocio.
- Integrar los datos con Power BI.
- Construir un proceso ETL utilizando Power Query y lenguaje M.
- Desarrollar un modelo analítico con relaciones y medidas DAX.
- Crear dashboards ejecutivos para la toma de decisiones.

## Ejecución de los scripts SQL

1. Abrir PostgreSQL mediante pgAdmin.
2. Crear una nueva base de datos llamada:

```
Ventas_Tech_DB
```

3. Abrir el Query Tool.
4. Ejecutar el script correspondiente del módulo.
5. Verificar que todas las tablas y registros se hayan creado correctamente.
6. Ejecutar las consultas SQL incluidas en los módulos M4 y M5.

## Observaciones

Algunas consignas del curso hacen referencia a campos como **Online/Presencial**, **segmento**, **territorios** e **id_categoria**, los cuales no estaban presentes en el dataset utilizado.

Por ese motivo se realizaron adaptaciones documentadas en cada módulo para mantener la coherencia del proyecto sin modificar la estructura original de la base de datos.
